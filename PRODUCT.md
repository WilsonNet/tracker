# Product

## Register

product

## Users

Solo musicians and audio recordists who want to capture multitrack recordings on their PC without the complexity of a full DAW. They value speed, keyboard fluency, and direct hardware-like interaction. They open the app in their studio or at their desk, instrument in hand, and want to start recording immediately.

## Product Purpose

A minimal multitrack audio recorder for the desktop. It provides the core recording workflow of a physical multitrack recorder (like the Zoom R4) — arm tracks, set levels, record, playback, overdub — with the speed and precision of Vim-style keyboard control. No timeline, no grid, no DAW complexity. Just record.

## Brand Personality

Functional. Precise. Keyboard-native.

Like a precision instrument: every control has a clear purpose, nothing is ornamental. The keyboard is the primary interface; the mouse is available but secondary. Input types match their function (sliders for EQ, toggles for arming, etc.). Modern and clean, not retro or skeuomorphic. Not a toy, not a sprawling pro tool — a focused instrument that rewards fluency.

## Anti-references

- **Pro Tools / Cubase**: Overwhelming complexity, tiny targets, cluttered toolbars, modal overload
- **GarageBand / beginner-first apps**: Toy-like, tutorial-heavy, icons everywhere, guided workflows
- **SaaS dashboards**: White cards, rounded corners, blue CTAs, onboarding wizards — this is a tool, not a service
- **DAW timeline paradigm**: No waveform grids, no arrange windows, no clip-based editing

## Design Principles

1. **Keyboard is primary, mouse is available.** Every action has a Vim key binding. Discovery through the UI, speed through the keyboard.
2. **One function, one control.** EQ uses sliders because that's what makes sense. Use the right input affordance for each task, not a uniform control library.
3. **Record-first, not edit-first.** The app is optimized for capturing performances, not post-production. Arm, level, record, listen.
4. **Minimum viable complexity.** Every feature must earn its place. When in doubt, leave it out. A missing feature is better than a confusing one.
5. **Fluency over discovery.** The interface rewards repeated use. Keyboard shortcuts build muscle memory. The UI teaches through consistent patterns, not tutorials.

## Accessibility & Inclusion

- WCAG 2.1 AA target
- Keyboard-first by design serves motor-impaired users
- Reduced motion support for all animations
- High contrast modes for studio/low-light environments
- Screen reader considerations for track state, levels, and transport status
